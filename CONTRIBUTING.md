# Contributing to PhantomMobile

First off, thank you for considering contributing to PhantomMobile! 🎉  
Your help is essential for keeping this project useful and up‑to‑date.

## 📌 Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md) (if you add one).  
In short: be respectful, constructive, and collaborative.

## 🧪 How Can I Contribute?

### Reporting Bugs

If you find a bug, please open an issue on GitHub and include:

- A clear, descriptive title.
- Steps to reproduce the behaviour.
- Expected vs. actual behaviour.
- Screenshots or screen recordings (if applicable).
- Environment details (Unity version, Android/iOS/HoloLens, device model).

### Suggesting Enhancements

We welcome ideas for new features or improvements.  
Please open an issue with the label `enhancement` and describe:

- What problem does it solve?
- How would it work from a user perspective?
- Any relevant references or examples.

### Pull Requests

We use the standard GitHub Pull Request workflow.

1. **Fork the repository** and create your branch from `main`.
2. If you’ve added or changed functionality, **update the documentation**.
3. Make sure your code **builds and runs** on at least one target platform (Android / HoloLens 2).
4. **Test your changes** on a physical device (if possible).
5. Open a Pull Request – describe **what** you changed and **why**.

> ⚠️ Large changes should be discussed in an issue **before** you invest a lot of time.  
> Open an issue with the `discussion` label first.

## 🔧 Development Setup

- Unity 2022.3 or newer (with Android Build Support)
- Vuforia / OpenXR package (as defined in the project)
- Git LFS (for large assets)

See the main [README](README.md) for build instructions.

## 📝 Style Guidelines

- Use **C#** standard conventions (PascalCase for methods / classes, camelCase for local variables).
- Keep code **readable** and comment non‑obvious logic.
- Follow the existing project structure (Assets/Scripts, Assets/StreamingAssets, etc.).

## ✅ Commit Messages

Write clear, concise commit messages in English.  
Example:  

Fix phantom recognition on devices without ARCore
Update DICOM slice alignment for CT volumes
